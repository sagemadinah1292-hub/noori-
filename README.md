# NOORI audio plugins

[NOORI CHOIR](voice-choir/README.md) is a Windows x64 / JUCE / VST3 choir-workflow plugin targeted at Cubase Pro 15, without ARA. It provides vocal import/capture, musical-part generation, waveform preview lanes, Post FX and synchronized stem export/dragging. The current voice engine is DSP; neural choir realism remains unfinished. See its README for exact build, verification and host limitations.

Other development branches contain the earlier NOORI TURAB TEMPO and double-delay work.
